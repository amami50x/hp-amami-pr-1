東京奄美会 HP管理台帳 — Googleスプレッドシート インポート手順
作成: 2026-06-22

【ファイル一覧】
  0_索引.csv       … ブックの説明（2列形式）
  1_共通.csv       … サーバ・FileZilla・権限
  2_公式HP.csv     … WordPress（公式HP）
  3_観光情報HP.csv … hp-amami-pr-1（観光情報）
  4_担当一覧.csv   … 管理者・Googleアカウント
  5_更新ログ.csv   … 変更履歴

【Googleスプレッドシートへの取り込み】
1. Googleドライブ → 新規 → Googleスプレッドシート
2. シート名を「0_索引」に変更
3. ファイル → インポート → アップロード → 0_索引.csv
   ※「現在のシートを置き換える」または「新しいシートを挿入」
4. 残り 1_共通 〜 5_更新ログ も同様に、シートを追加してインポート
5. 文字化けする場合: インポート時に文字コード「UTF-8」を選択

【一般管理者用シート（任意）】
  新シート「6_一般管理者用」を追加し、例:
  =FILTER('2_公式HP'!A:N,'2_公式HP'!I:I="一般")
  =FILTER('3_観光情報HP'!A:N,'3_観光情報HP'!I:I="一般")

【注意】
  - パスワードはCSV・スプレッドシートに書かない
  - 公開本文（投稿全文・index.html全文）はここに置かない
  - 更新したら 5_更新ログ に1行追加
