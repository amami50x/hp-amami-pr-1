おすすめの使い分け

ちょっと戻したい → Ctrl + Z

AIのこの作業を取り消したい → チャットの Restore ボタン

大きな区切り・1日の終わり・大事な作業前 → git add -A; git commit -m "..."

この3段構えにしておけば、もう「何時間もかけて戻す」ことはなくなります。

🌸これからは、作業前にこれだけで大丈夫です。
🌸git add -A; git commit -m "バックアップ"
おかしくなったらこれです。
🌸git reset --hard HEAD
特定ファイルだけ戻すなら：
🌸git checkout HEAD -- index.html
今後、私が作業を始める前には、必要なら先に
「まずバックアップを取りますか？」
と確認するようにします。

1. 文字の大きさ（コード欄）
やりたい
キー

文字を大きく
Ctrl + + （プラス）

文字を小さく
Ctrl + - （マイナス）

元のサイズに戻す
Ctrl + 0 （ゼロ）

何度も押すと、その分大きくなります。

2. 画面全体の大きさ（メニューも含めて全部）
やりたい
キー

全部大きく
Ctrl + Shift + =

全部小さく
Ctrl + Shift + -

目が疲れている時はこちらが便利です。

3. サイドバー（左の一覧）の表示／非表示
やりたい
キー

左のファイル一覧を出す／消す
Ctrl + B

右側のチャット欄を出す／消す
Ctrl + L（または Ctrl + I）

下のターミナルを出す／消す
Ctrl + `

コードに集中したい時 → Ctrl + B で左を消す
→ 画面が広く使えます。

4. ファイルをすばやく開く
Ctrl + P
→ 上に入力欄が出ます。
→ ファイル名の一部を入れるだけで候補が出ます（例：index と打つだけ）。
毎回フォルダから探すより、これが一番速いです。

5. 文字を検索したい
やりたい
キー

開いているファイルの中で検索
Ctrl + F

全ファイルから検索
Ctrl + Shift + F

検索した文字を別の文字に置換
Ctrl + H


6. 戻す（Undo）/ やり直し（Redo）
やりたい
キー

1つ前に戻す
Ctrl + Z

戻したのを取り消し
Ctrl + Y

これは「さっき書いたのを取り消したい」時のもの。
何度も押せば、押した回数だけ戻ります。

7. 画面を縦に2つに分ける（左右で別ファイル）
Ctrl + \
→ 同じファイルを左右に並べたり、左で HTML、右で CSS、のように見られます。
閉じるには、片方のタブを × で閉じます。

8. 保存
Ctrl + S

これだけは絶対覚えてください。
編集後に押さないと、ファイルに反映されません。
