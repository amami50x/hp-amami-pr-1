テーブル内リンク チェック（管理者用）

トップページ index.html の表に並ぶリンクの生死を確認できます。 通常のページ閲覧では、このチェック結果は表示されません。

② 結果を表示（赤枠・青枠で確認） 参考：通常表示（結果なし）

状況

赤枠：直URLが到達不能
青枠：遷移先に切れリンク有
グレー枠：URLが未設定
使い方：
1.「リンクチェックを実行」を押すと、サーバー側で link-status-check.php が動き、 link-status.json が更新されます。
2.「結果を表示」をクリックすると、別タブで index.html?admin=1 が開き、 異常セルだけ赤枠・青枠で表示されます。各セル右下の「詳細」ボタンで原因URLを確認できます。
3. ローカル環境で実行する場合は、PowerShell で python link-status-check.py を実行してから「結果を表示」を押してください。
管理者専用ページです。一般ユーザー向けの導線は持たせていません（noindex設定）。
