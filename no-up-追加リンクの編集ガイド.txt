==========================================================
 リンクの追加・編集ガイド（かんたん版）
==========================================================

■ 編集するファイル
  リンク一覧.txt   ← このファイルだけを編集します。
  ※ index.html（プログラム本体）は触りません。
  ※ 記号 { } " , は使いません。メモ帳でそのまま書けます。

■ 大事なこと（一元管理）
  ・表のリンクのURLは「リンク一覧.txt だけ」に入っています。
    index.html の表のセルにはURLは持たせていません（二重管理をなくすため）。
  ・つまり、このファイルが“唯一の正”です。ここを直せば、それがそのまま反映されます。
  ・逆に、ある行を消すと、そのセルのリンクは“完全になくなり”、
    文字だけの表示（クリックできない）になります。予備（フォールバック）はありません。

■ どうなる？
  ・表の全リンク（全市町村のセル・島の関連サイト・SNS）が、すべて
    このファイルに載っています。どのリンクも、ここで変更・追加・削除できます。
  ・1つのセルにリンクが2つ以上になると、自動で「項目名 ▾」の
    ポップアップに変わり、クリックで一覧が開きます。
  ・リンクが1つだけのセルは、今までどおりの表示（青いボタン・色や見た目もそのまま）です。
  ・名前が長くても大丈夫です（ポップアップ内で折り返して全文表示）。

■ リンク切れ（つながらないURL）を消したいとき
  ・そのリンクの行を「削除」するか、行の先頭に # を付けるだけです。
    例）# 体験 = https://example.com/dead-link   ← この行は表示されなくなります
  ・1つしかないセルの行を消すと、そのセルは文字だけ（リンクなし）になります。
    別のURLに差し替えたいときは、行を消さずにURL部分だけ書き換えてください。


 0. 一般管理者向け：リンク一覧はサーバー上で管理する（基本）
----------------------------------------------------------
ふだんは「さくらサーバー上で編集 → サーバー上でリンクチェック」を基本にします。
ローカル（パソコン内）の「リンク一覧.txt」は、通常は編集しません。
ローカルで確認・テストするときだけ、FileZillaでサーバーの最新版を
ダウンロードして使います。

【使い方】
  (1) HPのMENUから「リンク一覧 編集ページ」を開く。
        → link-editor.php が開きます。
  (2) パスワードでログインして、URLや名前を修正し「保存する」を押す。
        → サーバー上の「リンク一覧.txt」が更新され、HPに反映されます。
  (3) HPのMENUから「リンクチェック」を開く。
        → link-status-check.php が動き、「link-status.json」が更新されます。
  (4) 赤枠・灰色枠などの管理者向け表示を確認する。

【大切な注意】
  ・ローカルの「リンク一覧.txt」は編集しません。
  ・サーバー上の「リンク一覧.txt」を唯一の正とします。
  ・ローカルでテーブル表示を確認したい場合は、先にFileZillaで
    サーバー上の「リンク一覧.txt」と「link-status.json」を
    ローカルへダウンロードしてください。

【安心ポイント】
  ・管理者はファイルを探す必要がありません。HPのMENUから編集ページを開きます。
  ・保存するたびに、サーバーの tbl-url-bk フォルダへ
    日時つきのバックアップが自動で残ります。

※ この下の説明（1以降）は、「リンク一覧.txt」の書き方です。


----------------------------------------------------------
 1. 基本の書き方（これだけ覚えればOK）
----------------------------------------------------------
書くのは2種類だけです。

 (1) どこに出すか  →  [ ] で囲んで書く
 (2) 何を出すか    →  名前 ＝ URL  を1行ずつ書く

  例）

    [cell-01-13]
    ねりやかなや = https://www.neriyakanaya.jp/
    喜界町 移住・定住（公式） = https://www.town.kikai.lg.jp/...

★ ポイント
  ・「名前 ＝ URL」のかたちで1行に1つ書くだけ。
  ・＝（イコール）は半角 = でも全角 ＝ でもOK。
  ・[ ] も半角 [ ] でも全角 ［ ］ でもOK。
  ・# で始まる行と、空っぽの行は無視されます（メモに使えます）。
  ・カンマ , や かっこ { } " はいりません。


----------------------------------------------------------
 2. 名前は省略してもOK
----------------------------------------------------------
・名前を書かずに URL だけでもOKです。

    = https://www.neriyakanaya.jp/abc
    （または）
    https://www.neriyakanaya.jp/abc

  → そのときは長いURL全体ではなく「サイトのアドレス
    （ドメイン名）」が自動で表示されます。
       例）https://www.neriyakanaya.jp/abc  →  画面表示は「neriyakanaya.jp」
・できれば名前を付けたほうが分かりやすいです。


----------------------------------------------------------
 3. 並び順
----------------------------------------------------------
・「上に書いた順」でそのまま表示されます。
  → 優先したいリンクを上に書いてください。
・順番を変えたいときは、その行を上下に動かすだけです。
・元の公式リンクも出したい場合は、それも1行書いてください
  （書かないと出ません＝そのセルは“ここに書いた分だけ”出ます）。


----------------------------------------------------------
 4. どこに出すか（[ ] の書き方）
----------------------------------------------------------
●セルに出す  →  [cell-行番号-列番号]
    例）喜界町の「移住・定住」＝ [cell-01-13]

   【列番号】
     01 = 市町村名        08 = アクセス
     02 = 観光            09 = 天気
     03 = グルメ          10 = 市町村旗歌
     04 = 特産品          11 = 基本情報
     05 = 郷土芸能        12 = イベントカレンダー
     06 = 歴史文化        13 = 移住・定住
     07 = 体験            14 = ふるさと納税

   【行番号】（表の上から順）
     01 = 喜界町          07 = 徳之島町
     02 = 龍郷町          08 = 天城町
     03 = 奄美市          09 = 伊仙町
     04 = 大和村          10 = 和泊町
     05 = 宇検村          11 = 知名町
     06 = 瀬戸内町        12 = 与論町
     13 = 最終行（東京奄美会・広域事務組合など）

●島の「関連サイト」に出す  →  [島:島名]
    使える島名（この5つ）：
      奄美大島 / 喜界島 / 徳之島 / 沖永良部島 / 与論島
    例）
      [島:喜界島]
      概要 = https://kikaijimanavi.com/tourism/

●最終行の「SNS一覧」に出す  →  [SNS]
    例）
      [SNS]
      X（旧Twitter）：東京奄美会 = https://x.com/PiiZmi


----------------------------------------------------------
 5. 編集したあと（基本手順：サーバーが正）
----------------------------------------------------------
ふだんはサーバー上で編集します。ローカルでは編集しません。

  (1) HPのMENUから「リンク一覧 編集ページ」を開く。
  (2) サーバー上で「リンク一覧.txt」を編集して保存する。
       → 保存時に tbl-url-bk フォルダへ自動バックアップされます。
  (3) HPのMENUから「リンクチェック」を実行し、
       サーバー上の「link-status.json」を更新する。
       → 赤枠・灰色枠などの管理者向け表示は、このファイルで決まります。
  (4) 必要に応じて、ローカル確認用にFileZillaで
       「リンク一覧.txt」と「link-status.json」をダウンロードする。

・もし書き方を間違えても、ホームページ本体は正常に表示されます。
  その行のリンクが出ないだけなので、落ち着いて直してください。

【link-status.json について】
  ・「リンク一覧.txt」を保存しただけでは、自動では更新されません。
  ・HPのMENUからリンクチェックを実行すると、現在のURL状態を調べて
    サーバー上の「link-status.json」が新しく作られます。
  ・赤枠が残る場合は、リンクは直っていても「link-status.json」が古い
    可能性があります。リンクチェックを実行してください。

【バックアップについて】
  ・サーバー上で保存した控え（バックアップ）はすべて
    tbl-url-bk フォルダにたまります。
  ・古いものが増えてきたら、tbl-url-bk の中の古いファイルを
    手で削除して問題ありません（最新のリンク一覧.txt が正です）。


----------------------------------------------------------
 6. よくある質問
----------------------------------------------------------
Q. 名前に「＝」が入っているときは？
  A. 行の最初の「＝」までが名前、その後ろがURLになります。
     名前に＝が必要なときは「:」などに置き換えてください。

Q. リンクを1つだけにしたい（ポップアップにしたくない）
  A. その [cell-○○-○○] の下のリンクを1行だけにすればOKです。
     2つ以上書くと自動でポップアップになります。

Q. メモ（コメント）を残したい
  A. 行の先頭に # を付ければ、その行は無視されます。


----------------------------------------------------------
 7. まるごとコピーして使えるひな形
----------------------------------------------------------
新しいセルを追加したいときは、下を丸ごとコピーして
番号・名前・URLを書き換えてください。

    [cell-○○-○○]
    1つ目の名前 = https://1つ目のURL
    2つ目の名前 = https://2つ目のURL
